# Planned implementations

The report covers three scenarios. The executable demo currently implements only the non-uniform-flow, constant-swimmer-speed case. The other two cases are intentionally left for existing scripts supplied by the project author:

1. `cases/uniform_flow_constant_speed/` — constant uniform current and constant swimmer speed.
2. `cases/uniform_flow_exponential_fatigue/` — constant uniform current and exponentially decreasing swimmer speed.

No implementation code was generated for either of these two cases.
